**Document Version:** 1.0.0  
**Infrastructure Stack:** Cloudflare Ecosystem (Pages + Workers + D1 + R2 + KV)

### 2. Frontend Technology Stack
- **Library:** React 19.x with functional components and hooks.
- **Language:** TypeScript 5.7+ (strict mode, no implicit any).
- **Bundler:** Vite 6.x configured for PWA output and chunk optimization.
- **Styling:** Tailwind CSS v4 with custom variant `@custom-variant dark (&:where(.dark, .dark *));`.
- **Icons:** `lucide-react` (SVG, tree-shaken).
- **Offline Storage:**
  - `IndexedDB` with custom wrapper `StorageEngine`.
  - Service Worker cache for app shell (`/`, `/index.html`, `/assets/*`, logos, fonts).
  - Outbox synchronization pattern for mutation offline replay.

### 3. Edge Backend & Cloudflare Services

#### 3.1 Cloudflare Workers (Serverless API)
- **Runtime:** Cloudflare Workers running V8 isolates with 0ms cold-start latency.
- **Routing Engine:** Lightweight router (Hono or native Worker Router).
- **Proxy Routes:** All Gemini AI calls, third-party notifications, and financial exports pass through server-side Worker endpoints (`/api/ai/*`, `/api/reports/*`, `/api/vouchers/*`).
- **No Client Secrets:** No client-side environment variable ever exposes secret API keys.

#### 3.2 Cloudflare D1 (Serverless Relational Database)
- Native edge SQLite database distributed across Cloudflare locations.
- Prepared statement queries preventing SQL injection.
- Schema migration scripts managed via Wrangler (`wrangler d1 migrations`).
- Read replication at the edge for sub-10ms ledger queries.

#### 3.3 Cloudflare R2 (Object Storage for Attachments)
- S3-compatible, zero-egress fee storage for bill attachments, invoice scans, batch release certificates, and machine maintenance photos.
- Presigned URL uploads generated by Workers so clients never touch bucket credentials directly.

#### 3.4 Cloudflare KV (Key-Value Store)
- Used for distributed rate limiting, revoked JWT session blacklists, temporary OTP verification codes, and daily currency/commodity price caches.

#### 3.5 Cloudflare Turnstile & WAF
- Free CAPTCHA alternative protecting login endpoints and high-volume public forms from brute-force attacks and credential stuffing without UX friction.

### 4. AI Engine Integration: Google Gemini Flash
- **Model Selected:** `gemini-3.8-flash` / `gemini-2.5-flash`.
- **Calling Strategy:**
  - 100% server-side execution via Cloudflare Worker (`/api/ai/analyze-batch`).
  - Strict system prompts preventing prompt injection.
  - JSON schema output enforcement (`response_mime_type: "application/json"`).
- **Core AI Capabilities:**
  1. **Batch Scrap Anomaly Detection:** Compares current batch yield and spill grams against historical averages for the specific pack format.
  2. **Raw Material Price Trend Advisory:** Recommends optimal APMC cumin/chilli powder procurement timing based on purchase history.
  3. **Third-Party vs Own Machine Payback Simulator:** Computes daily net savings of shifting ₹10 strip work in-house based on real production volume.

### 5. Offline-First Synchronization Protocol

```
[ User Interaction ] 
        |
        v
[ Local State & IndexedDB / LocalStorage ] ---> [ Instant UI Render (0ms) ]
        |
        v
[ Outbox Event Queue ] 
  (Action, Entity, Payload, Timestamp, DeviceID, Status: 'pending')
        |
   (Network Online Event Detected)
        v
[ Sync Service Worker ]
        |
        v (POST /api/sync/batch-outbox)
[ Cloudflare Worker Edge Validator ]
        |
   (Conflict Resolution: Last-Write-Wins with Optimistic Locking / Version Flag)
        v
[ Cloudflare D1 Commit ] ---> [ Returns 200 OK + Updated Server Sequence ]
        |
        v
[ Outbox Queue Cleaned ]
```

### 6. Edge Performance & Caching Strategy
- **Static Assets:** Cached on Cloudflare CDN with `Cache-Control: public, max-age=31536000, immutable`.
- **HTML Document:** `Cache-Control: public, max-age=0, must-revalidate` ensuring instantaneous PWA service worker updates.
- **D1 Database Reads:** Edge cache with stale-while-revalidate for read-heavy summaries (e.g. Master SKU lists, Machine catalogues).
